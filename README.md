[README.md](https://github.com/user-attachments/files/35213054/README.md)# UCAS 实安课堂 · 题库驱动全自动学习助手

> 适用于**中国科学院大学实验室安全育人智慧学习系统**课程页面的 Tampermonkey 用户脚本。v2.0.0 引入独立题库文件，优先按题目 ID、题干和选项匹配标准答案；题库未命中时，再使用 DeepSeek 深度思考、联网核实和可选独立复核。视频播放、答题提交、刷新定位及自动切课仍沿用网站原有页面流程。
>
> **当前版本：v2.0.0｜作者：Zyoung&GPT｜非官方项目｜仅供个人学习与技术交流**

## ✨ 主要功能

| 功能 | 说明 |
| --- | --- |
| **本地题库优先（v2.0）** | **引入 4304 道题、20 个类别的独立 JSON 题库；命中后直接使用标准答案，不请求 DeepSeek** |
| **精准匹配** | 优先读取网页 Vue 状态中的题目 ID；无法读取 ID 时，使用题干和选项文本联合匹配 |
| **选项顺序映射** | 即使页面选项顺序变化，也会按选项文本映射回当前页面字母；无法唯一匹配时不使用题库答案 |
| 判断 / 单选 / 多选 | 根据页面实际单选框、复选框校验题型，并解析 `correctAnswer` 中的全部答案字母 |
| **多选题逐项校验** | 逐一勾选并等待 Vue 更新，核对所有选项后才提交 |
| **DeepSeek 兜底** | 题库未命中时，保留原有深度思考、联网搜索和可选独立复核流程 |
| **题库自动更新** | 从 GitHub Raw 获取 JSON；本地缓存可用，默认每 24 小时检查一次，也可在面板手动更新 |
| 自动播放 | 检测课程中的 HTML5 视频，按照设定倍速播放 |
| 自动检测弹题 | 识别标题为「视频习题」的弹窗，无需手动点击「识别并解题」 |
| 自动提交与续播 | 勾选验证成功后点击网页自身的「提交」按钮，等待网站恢复视频 |
| **刷新后自动定位** | 网页加载课程树后，先找出首个「未学」或进度不足 100% 的视频 |
| **视频结束后刷新** | 视频正常结束并等待网站记录后刷新页面，重新读取最新的课程完成状态，再继续未完成课程 |
| 自动跨章节 | 检查各大章节，必要时展开课程树，找到下一个未完成视频 |
| 状态与日志 | 提供运行状态、答案来源、匹配方式、错误提示及日志导出 |
| 暂停与手动操作 | 可随时暂停；支持手动识题与手动切课 |

## 🔁 运行流程

```text
进入课程页面（包括刷新后）
    ↓
等待课程目录加载 → 查找首个未完成视频
    ↓
点击课程并确认视频已切换 → 开始播放
    ↓
检测到「视频习题」弹窗
    ↓
读取题目 ID、题干、题型和 A/B/C/D 选项
    ↓
优先按题目 ID 查询本地题库
    ├─ 命中：校验题干 / 选项 / 题型 → 解析 correctAnswer
    │       ↓
    │   按页面当前字母逐项勾选 → 核对所有选项 → 网站原有按钮提交
    │
    └─ 未命中：按题干 + 选项文本精确匹配
            ├─ 命中：执行相同的勾选、校验和提交流程
            └─ 未命中 / 有歧义：回退 DeepSeek
                    ↓
                深度思考 → 官方联网搜索核实 → 可选独立复核
                    ↓
                校验通过后逐项勾选并提交
    ↓
网站处理答题并恢复播放
    ↓
视频播放结束 → 等待平台记录进度（默认约 8.5 秒）
    ↓
刷新网页 → 重新获取课程目录
    ↓
自动定位并播放首个未完成视频（循环）
```

**说明：** 脚本不会通过修改后台数据来伪造课程完成状态；学习进度是否被记录，以网站实际显示为准。自动答题可能出错，请自行核对实验室安全知识。

## 📦 安装要求

- Chrome、Edge 或其他支持 Tampermonkey 的浏览器。
- 已安装并启用 [Tampermonkey](https://www.tampermonkey.net/)。
- 能正常访问学校的实验室安全育人智慧学习系统。
- **题库命中不需要 DeepSeek API Key**；若希望题库未命中时自动调用 DeepSeek 兜底，则需要可用的 API Key，API 调用可能产生费用。
- GitHub 仓库根目录需要同时存在 `ucas-study.user.js` 和 `ucas_all_20_categories_4304_raw.json`。

### 安装步骤（推荐：GitHub Raw 一键安装）

无需下载 ZIP 或手动复制代码，直接从 GitHub 安装：

1. 先在浏览器中安装并启用 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击进入仓库的 **[ucas-study.user.js 代码页面](https://github.com/lfssgg/safety-test-gkd/blob/main/ucas-study.user.js)**。
3. 在代码页面**右上方点击 `Raw`**，打开脚本原始内容。
4. Tampermonkey 通常会自动弹出「安装用户脚本」页面，检查脚本名称及来源后点击**「安装」**即可。
5. 返回 Tampermonkey 管理面板确认脚本已启用，**禁用以前安装的 v1.1 / v1.2 / v1.3 或其他同类脚本**，避免重复运行。
6. 登录课程网站并打开课程详情页。题库匹配无需 API Key；如需题库未命中时使用 DeepSeek 兜底，在助手「设置」中填写自己的 **DeepSeek API Key** 并保存。点击「开始全自动学习」后，脚本会优先使用题库；开启自动恢复后，刷新页面也会尝试自动运行。

**快捷入口：** [点击直接打开 Raw 安装地址](https://raw.githubusercontent.com/lfssgg/safety-test-gkd/main/ucas-study.user.js)。

**如果点击 Raw 后只显示代码或下载文件，没有出现安装页面：** 请先确认 Tampermonkey 已安装并启用；然后下载 [`ucas-study.user.js`](./ucas-study.user.js)，在 Tampermonkey「管理面板」→「实用工具」→「导入」中选择该文件进行安装。不同浏览器或 Tampermonkey 版本的按钮名称可能略有不同。

> 如果浏览器阻止自动播放，需要先在网页中手动点击一次视频播放键。

## 🔄 GitHub 自动更新

脚本已设置固定的 GitHub 更新地址，Tampermonkey 会按自身检查周期比较在线脚本的 `@version` 版本号：

```javascript
// @updateURL    https://raw.githubusercontent.com/lfssgg/safety-test-gkd/main/ucas-study.user.js
// @downloadURL  https://raw.githubusercontent.com/lfssgg/safety-test-gkd/main/ucas-study.user.js
```

**首次启用：** 先从上述 [安装地址](https://raw.githubusercontent.com/lfssgg/safety-test-gkd/main/ucas-study.user.js) 重新安装一次带更新元数据的脚本，并停用旧版。以后更新通过 Tampermonkey 检查即可；**仅上传到 GitHub 不会令以前安装的脚本自动具备更新地址**。

**发布脚本新版：**

1. 编辑仓库根目录的 `ucas-study.user.js`，保持文件名和路径不变。
2. 同时增加头部的 `// @version` 和源码中的 `const VERSION`，例如从 `2.0.0` 升为 `2.0.1`。
3. 提交到 `main` 分支，等 GitHub Raw 文件可访问后，Tampermonkey 才能发现更新。
4. 在 Tampermonkey 中检查脚本自动更新是否启用；也可以在管理面板手动检查更新。更新时间取决于扩展设置、网络及浏览器运行状态，**不是推送到 GitHub 就立刻同步**。

**只更新题库：**

- 将新的 `ucas_all_20_categories_4304_raw.json` 上传到仓库根目录并保持文件名不变。
- 用户端默认每 24 小时检查一次题库更新；也可以在助手「设置」中点击 **「检查 / 更新题库」** 立即拉取。
- 题库下载成功后会缓存到 Tampermonkey 存储；网络暂时不可用时继续使用已有缓存。
- 仅更新 JSON 不需要提升脚本 `@version`，也不需要用户重新安装脚本。

本项目目前假定仓库使用 `main` 分支。如果你改用其他默认分支，必须同步修改脚本中的两个 URL，已经安装的旧客户端也需要重新导入正确版本。

## ⚙️ 配置选项

| 设置项 | v2.0 默认值 | 作用 |
| --- | --- | --- |
| **优先使用本地题库** | **开启** | 命中题库时直接读取标准答案，不调用 DeepSeek |
| **题库状态 / 手动更新** | 自动 | 面板显示题库数量、缓存 / 在线状态；可手动检查更新 |
| DeepSeek API Key | 空 | 仅题库未命中时需要，形如 `sk-...` |
| 文字题模型 | `deepseek-v4-pro` | 文字题优先使用 Pro；图片题自动使用 Flash |
| 思考强度 | `high` | 启用 DeepSeek 深度思考；可手动改为 `max`、`low`、`none` |
| 二次独立复核 | **开启** | 文字题由不同模型复核，答案不一致时停止自动提交 |
| **联网核实答案** | **开启** | 自动使用 `deepseek_web_search` 进行网页检索；只有返回真实来源且与首轮答案相符，才允许继续 |
| 课程参考资料 | 空 | 可粘贴学校实验室安全规范内容，随题目发送给 API |
| 播放速度 | `1.5×` | 可选择 `1×`、`1.25×`、`1.5×`、`1.75×`、`2×` |
| 自动切换下一课程 | 开启 | 当前视频正常结束后继续下一个未完成课程 |
| 刷新后定位未完成视频 | **开启** | 启动时先读取目录标记，不能直接播放网页默认课程 |
| 视频完成后刷新网页 | **开启** | 正常结束后等待平台写入记录，然后刷新网页重新获取进度 |
| 检测到题目自动解题 | 开启 | 先查题库；未命中时自动调用 DeepSeek（需 API Key） |
| 自动勾选答案 | 开启 | 自动选择题库标准答案或 AI 建议答案，并检查选中状态 |
| 自动提交视频习题 | 开启 | 仅在实际选项与建议答案完全一致时尝试提交 |
| 刷新后自动恢复 | 开启 | 题库优先模式开启时可自动恢复；AI 兜底仍需要 API Key |

**模型注意：** DeepSeek 兜底默认文字题使用 `deepseek-v4-pro`，包含图片的题目自动改用 `deepseek-flash`（Pro 不支持视觉输入），均使用 `reasoning_effort: high`。模型可用性和费用请查看 [DeepSeek API 文档](https://api-docs.deepseek.com/)。

## 🚀 v2.0.0 大版本更新：正式引入本地题库

v2.0.0 将原来完全依赖 DeepSeek 分析题目的流程，升级为 **「本地题库优先 + DeepSeek 兜底」**。题库与用户脚本分开存放，方便后续单独更新题库，不必每次都重新安装脚本。

### 题库规模

本次接入的 JSON 文件来自题库数据，包含 **4304 道题、20 个类别**：

| 题型 | 数量 |
| --- | ---: |
| 判断题 | 2465 |
| 单选题 | 1227 |
| 多选题 | 612 |
| **合计** | **4304** |

20 个类别包括：应急处置、辐射安全、废物处置、水电安全、基础操作、用气安全、土建安全、试剂安全、通识安全、安全防护、特种设备、消防安全、网络安全、生物安全、机电安全、仪器设备、隐患辨识、安全标识、安全检查、安全规范。

题库中有 185 条记录带有 `picUrl` 图片路径。另有部分题干重复，因此脚本不会仅凭题干就直接选答案。

### 匹配策略

1. **优先按题目 ID 匹配**：从当前「视频习题」Vue 组件状态中读取 `questionId`，与题库 `id` 对应。
2. **题干和选项复核**：即使 ID 命中，也会检查题干、选项和题型，避免题目数据不一致时误用答案。
3. **无 ID 时联合匹配**：按规范化题干查找候选，再用选项文本进行唯一匹配；如果页面选项顺序变化，会根据文本重新映射当前 A/B/C/D。
4. **多选题完整解析**：读取 `correctAnswer` 中的全部字母，例如 `A,C`、`B,C,D`，逐项勾选并等待 Vue 状态更新，最后核对所有选项。
5. **不确定时拒绝题库匹配**：重复题干无法区分、选项不一致、题型冲突或答案格式异常时，不会强行使用题库答案，而是回退 DeepSeek。

题库中有两条 `kind=1` 但 `correctAnswer` 包含多个字母的记录。脚本会同时检查页面实际控件类型与题库题型；如果单选 / 判断页面与多答案记录冲突，就不会把多个答案硬塞进单选框。

### 题库更新与缓存

- 在线地址：[`ucas_all_20_categories_4304_raw.json`](https://raw.githubusercontent.com/lfssgg/safety-test-gkd/main/ucas_all_20_categories_4304_raw.json)。
- 开启题库优先时，脚本启动先读取本地缓存，再从 GitHub Raw 检查更新。
- 默认每 24 小时检查一次；可在助手面板「设置」中点击 **「检查 / 更新题库」**。
- 更新失败时继续使用本地缓存；如果没有可用缓存或当前题目未命中，且已配置 API Key，才会尝试 DeepSeek 兜底。
- 题库 JSON 与用户脚本分开更新。只更新 JSON 时，无需修改脚本版本号。

### DeepSeek 的定位

题库命中时，脚本直接读取标准答案，不发送该题到 DeepSeek，也不需要 API Key。题库未命中时，才进入原有 v1.6 AI 流程：深度思考、官方联网搜索核实，以及可选的第二轮独立复核。AI 结果分歧、缺少搜索来源或置信度不足时，仍会停止自动提交。

### 本次修改范围

v2.0.0 主要改造答题模块，保留原有 HTML5 视频播放、倍速、视频结束刷新、刷新后定位未完成课程、跨章节切课、自动续播和日志功能。仍只处理课程视频中的「视频习题」，不自动提交考试页面，也不修改平台后台学习记录。

## 🔎 历史功能：v1.6 引入联网搜索核实答案

v1.6 为 DeepSeek 兜底流程引入了官方原生联网工具。**无需另外购买或配置 Tavily、Serper 等第三方搜索服务**：在 DeepSeek API Key 下即可通过 `deepseek_web_search` 进行查证。参考：[官方发布公告](https://api-docs.deepseek.com/zh-cn/news/news261113/) 和 [联网工具文档](https://api-docs.deepseek.com/zh-cn/guides/web_tools/)。

**默认开启的工作步骤：**

1. **首轮判断**：原有 `deepseek-v4-pro`（文字）或 `deepseek-flash`（图片）使用深度思考和 `checks` 对每一个选项进行判断。
2. **联网查证**：另外调用一次 `deepseek-flash`，向 Chat Completions API 传递 `tools: [{type: 'deepseek_web_search'}]`。搜索前会完整发送题干、题型和选项；模型尝试联网检索安全规范和其他可用资料。
3. **严格核验**：脚本检查响应中的服务端 `server_tool_calls` / `usage.server_tool_use`，并从**实际工具结果**读取来源网址。若未实际搜索、没有来源、答案 JSON 格式错误、某项 `checks` 与答案不匹配，或者联网结果与首轮答案不一致，都会**拒绝自动提交**。
4. **第三轮复核（可选）**：若仍开启「二次独立复核」，再调用一次原有的独立复核流程；全部通过后才按真实网页的选项逐个勾选并提交。
5. **查看证据**：助手面板和运行日志会显示联网核实结果及部分来源网址，方便自行查看原始资料。

**请求格式注意：** 官方规定，声明了联网工具的 Chat Completions 请求不能使用 `response_format: {type:'json_object'}`，否则会返回 HTTP 400。v1.6 的联网请求改用默认文本输出，并在本地严格解析和校验 JSON；首轮和原有独立复核仍按先前的 JSON 模式运行。

**费用与速度：** 默认三轮模型请求（首轮分析 + 联网查证 + 独立复核）会比 v1.5 慢，并增加 Token 消耗。按照 DeepSeek 官方 [价格说明](https://api-docs.deepseek.com/quick_start/pricing/)，自 2026 年 11 月 18 日起服务器端搜索/抓取工具调用本身不再额外收费，但联网返回内容仍计入模型 Token 费用。若想减少一次调用，可在脚本设置中关闭「二次独立复核」；不推荐关闭联网核实。

**可靠性提醒：** 网络搜索的结果也可能不准确、过时，或不符合本校课程的具体规定。脚本能验证模型**是否真的搜索并引用了网页**，但**无法自动证明网页内容及最终答案一定正确**。没有足够资料或三轮意见分歧时，自动学习会停在题目等待人工核对。本项目发布文件不包含 API Key；模拟接口测试不等于真实 DeepSeek 请求的端到端验证，也不能证明答案准确率。

## 🧠 v1.5 更新：提高答题可靠性（不保证正确率）

v1.4 的 `reasoning_effort: none` 关闭了模型思考；v1.5 重点改进答案生成和校验流程：

1. **深度思考默认开启**：默认 `high`；文字题优先使用 `deepseek-v4-pro`，图片题使用支持视觉的 `deepseek-flash`。
2. **逐个审查选项**：新提示词强调识别“错误的是”“不属于”“不能”等反向问法，并要求对所有选项输出 `checks: {A: true, ...}`；脚本验证 `checks` 和 `answers` 一致才允许继续。
3. **第二轮独立复核**：默认开启。文字题首轮用 Pro 时，第二轮用 Flash 独立回答；两轮答案完全一致、且都不报告低置信度时才尝试勾选提交。含图片题的两轮均由 Flash 执行，结果可能相关，并不能视为真正独立来源。
4. **存疑时不提交**：AI 拒答、未给出完整判断、两次答案不一致或复核请求失败，会停在题目页等待人工确认。这会中断无人值守流程，是为了减少明显的错误提交。
5. **课程参考资料（可选）**：面板可以粘贴院校的实验室安全规范或课程材料。其文本会随题目发给 DeepSeek；不要填写隐私信息或 API Key。

**重要限制：** 两个模型一致不代表答案必然正确。网站可能有本校教材专用判断标准；如实际正确率仍低，建议提供至少 5 道脱敏的题目、模型答案、平台正确答案，按“读题错误 / 知识错误 / 选项映射错误”分类修正。当前脚本不自动读取后台标准答案，也无法用模拟测试测量真实正确率。

**API 费用和速度：** 开启联网核实及第二轮复核会增加接口调用、Token 使用量和等待时间。首次升级 v1.5 时，会把沿用旧版默认 Flash 的模型设置切换为 Pro，同时保留原有的 API Key、倍速及其他设置。若需要节省调用费用，可在设置中关闭“二次独立复核”或切回 Flash。

## 🆕 v1.4 更新：刷新后自动查找未完成课程

网站在课程内部切换视频时，并不会同步修改浏览器地址栏的课程 `id`。因此即使上一节已经学完，刷新后平台仍可能按旧 URL 选中 JCXL01 等已完成课程。此前脚本在初始化后直接尝试播放默认视频，于是出现重复观看的现象。

v1.4 修改为：

1. **进入网页或刷新后不立即播放**，先等待课程树的数据加载。
2. 按网页目录顺序扫描各大章节，识别 `(学完)`、`(未学)`、`(44%)` 等标记。`(学完)` 或 `(100%)` 跳过，未学或不足 100% 的视频属于待完成课程。
3. 如有必要，展开尚未展开的大章节；遇到第一个待完成视频，就通过站点原本的课程树点击进入。
4. **确认当前视频或标题确实完成切换，才允许自动播放**；如果目录未加载或切换失败，停下来并在日志中提示，避免误播已完成课程。
5. 视频自然结束后，留出约 8.5 秒让网站记录完成进度，然后执行正常刷新；刷新完成后重新执行 1–4。

这两项行为均可在设置中独立关闭：**「进入或刷新网页时，自动定位首个未完成视频」**、**「视频正常结束后刷新网页，读取平台最新进度」**。建议保持开启。

**注意：** 这只使用网页显示的服务器返回进度，不主动改写数据库，也无法保证平台记录成功。如果服务器尚未把本节标记为完成，刷新后它仍会被判定为未完成，脚本可能再次播放该节。请检查右侧日志和左侧真实进度标记。

## 🛠️ v1.3 更新：修复多选题只选中一项

部分多选题使用 Vue / Ant Design Vue 的 `checkbox-group`。如果脚本连续同步点击 A、C，后一次的状态更新可能覆盖前一次，导致只勾选 C。

v1.3 改为：

1. 按 DeepSeek 返回的答案逐项点击。
2. 每次点击后等待网页状态更新，并确认该选项已选中。
3. 全部处理完成后，再检查**所有选项**的真实选中状态。
4. 只有实际选项与 AI 返回的答案完全一致，才允许自动提交；不一致时停止提交并保留弹窗供人工处理。

脚本不会自动覆盖已经由用户手动勾选的选项。

## ❓ 常见问题

<details>
<summary>弹出题目后没有自动答题？</summary>

确认脚本正在运行，并查看面板中的题库状态。题库命中不需要 API Key；若题库未命中，才需要填写 DeepSeek API Key 并开启「检测到题目自动解题」。目前仅针对课程视频中的「视频习题」弹窗，**不处理考试页面**。如果网站改版，题目结构可能需要重新适配。
</details>

<details>
<summary>显示 DeepSeek HTTP 错误？</summary>

检查 API Key、账户余额、网络连接，以及「模型」是否被当前 DeepSeek API 支持。可以展开日志查看具体报错。图片选项还要求所选模型和接口支持图片输入。
</details>

<details>
<summary>多选题为什么没有提交？</summary>

v2.0 会先读取题库 `correctAnswer` 的完整答案集合；多选题按字母逐项勾选并核对。如果题库未命中，则回退 DeepSeek；任何情况下，只要页面实际勾选状态与答案不一致，就不会自动提交。可查看日志中的「题库命中」「选项已勾选并确认」或「已核验勾选完成」信息。
</details>

<details>
<summary>视频播放完了，没有自动进入下一课？</summary>

确认已启用「自动切换下一课程」「刷新后定位未完成视频」「视频完成后刷新网页」。刷新后先等待课程树加载。若页面显示的完成进度没有更新，脚本会把原视频视为未完成；请检查后台是否成功记录，并查看助手日志。
</details>

<details>
<summary>网页上的操作面板不出现？</summary>

确认网址属于 `ucas.jcedutec.cn`，脚本已启用，并刷新课程页。若同时安装其他实验室安全助手，请先停用，避免冲突。
</details>

<details>
<summary>打开脚本时中文显示乱码？</summary>

请使用 UTF-8 编码打开文件。仓库中的 `ucas-study.user.js` 使用 UTF-8 BOM 以改善部分 Windows 编辑器的识别情况。
</details>

## 🔐 隐私、安全与限制

- **不要将 API Key 上传到 GitHub。** 请在油猴脚本的设置面板中填写，脚本通过 Tampermonkey 存储设置。
- 题库 JSON 从 GitHub Raw 下载并缓存在 Tampermonkey 中。**题库命中时不会把该题发送给 DeepSeek**；只有题库未命中且启用 AI 兜底时，题目文字、选项文本及可能存在的图片 URL 才会发送至 `https://api.deepseek.com/chat/completions`。请确认符合自己的数据使用要求。
- AI 可能产生错误答案或无法判断的结果；**尤其是实验室安全题目，请以学校要求和正式安全规范为准**。
- 仅适配已确认的网站视频习题 DOM；题型、页面结构或接口升级后可能失效。
- 不绕过平台对视频播放的限制，不伪造学习时长或完成状态，也不自动提交整场考试。
- 如遇系统异常，请先点击「暂停」，必要时禁用脚本并使用原网页完成学习。
