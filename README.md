# UCAS 实安课堂 · DeepSeek 全自动学习助手

> 适用于**中国科学院大学实验室安全育人智慧学习系统**课程页面的 Tampermonkey 用户脚本。通过 DeepSeek API 辅助识别视频随堂习题，并按网站原有的播放、提交与课程切换流程运行。
>
> **当前版本：v1.4.0｜非官方项目｜仅供个人学习与技术交流**

## ✨ 主要功能

| 功能 | 说明 |
| --- | --- |
| 自动播放 | 检测课程中的 HTML5 视频，按照设定倍速播放 |
| 自动检测弹题 | 识别标题为「视频习题」的弹窗，无需手动点击「识别并解题」 |
| DeepSeek 辅助解题 | 读取题干、选项及题型，通过 API 获取建议答案和简短解析 |
| 单选 / 判断 / 多选 | 根据页面单选框、复选框区分题型 |
| **多选题逐项校验** | **v1.3 修复**：逐一勾选并等待 Vue 更新，核对所有选项后才提交 |
| 自动提交与续播 | 勾选验证成功后点击网页自身的「提交」按钮，等待网站恢复视频 |
| **刷新后自动定位** | 网页加载课程树后，先找出首个「未学」或进度不足 100% 的视频，避免播放网站默认选中的已完成视频 |
| **视频结束后刷新** | 视频正常结束并等待网站记录后刷新页面，重新读取最新的课程完成状态，再继续未完成课程 |
| 自动跨章节 | 检查各大章节，必要时展开课程树，找到下一个未完成视频 |
| 状态与日志 | 提供运行状态、AI 建议、错误提示及日志导出 |
| 暂停与手动操作 | 可随时暂停；支持手动识题与手动切课 |

## 🔁 运行流程

```text
进入课程页面（包括刷新后）
    ↓
等待课程目录加载 → 查找首个未完成视频
    ↓
点击课程并确认视频已切换
    ↓
开始播放视频
    ↓
检测到「视频习题」弹窗
    ↓
读取题干、题型和 A/B/C/D 选项
    ↓
调用 DeepSeek API 获取建议答案
    ↓
逐项选择 → 核对页面实际勾选状态
    ↓
匹配成功 → 使用网站原有按钮提交
    ↓
网站处理答题并恢复播放
    ↓
视频播放结束 → 等待平台记录进度（默认约 8.5 秒）
    ↓
刷新网页 → 重新获取课程目录
    ↓
自动定位并播放首个未完成视频（循环）
```

**说明：** 脚本不会通过修改后台数据来伪造课程完成状态；学习进度是否被记录，以网站实际显示为准。自动答题可能出错，请自行核对实验室安全知识。

## 📦 安装要求

- Chrome、Edge 或其他支持 Tampermonkey 的浏览器。
- 已安装并启用 [Tampermonkey](https://www.tampermonkey.net/)。
- 能正常访问学校的实验室安全育人智慧学习系统。
- 已开通 DeepSeek API，并持有可用的 API Key；API 调用可能产生费用。

### 安装步骤

1. 推荐直接打开 **[安装最新版油猴脚本](https://raw.githubusercontent.com/lfssgg/safety-test-gkd/main/ucas-study.user.js)**，让 Tampermonkey 识别并安装；如果浏览器仅下载文件，也可下载 [`ucas-study.user.js`](./ucas-study.user.js) 后通过 Tampermonkey 的「实用工具」→「导入」安装。
2. 在 Tampermonkey 中选择「管理面板」→「实用工具」→「导入」，选择上述 `.user.js` 文件并安装。
3. **禁用旧版 v1.1 / v1.2 或其他同类脚本**，避免多个自动学习助手同时操作网页。
4. 登录课程网站并打开课程详情页，右下角应显示「实安课堂 · DeepSeek 助手 v1.4.0」。
5. 展开「设置」，填写自己的 **DeepSeek API Key**，按需调整模型、倍速及自动化选项，点击「保存设置」。
6. 首次配置后可点击「开始全自动学习」；开启自动恢复且已配置 Key 时，刷新页面也会尝试自动运行。

> 如果浏览器阻止自动播放，需要先在网页中手动点击一次视频播放键。

## 🔄 GitHub 自动更新

脚本已设置固定的 GitHub 更新地址，Tampermonkey 会按自身检查周期比较在线脚本的 `@version` 版本号：

```javascript
// @updateURL    https://raw.githubusercontent.com/lfssgg/safety-test-gkd/main/ucas-study.user.js
// @downloadURL  https://raw.githubusercontent.com/lfssgg/safety-test-gkd/main/ucas-study.user.js
```

**首次启用：** 先从上述 [安装地址](https://raw.githubusercontent.com/lfssgg/safety-test-gkd/main/ucas-study.user.js) 重新安装一次带更新元数据的脚本，并停用旧版。以后更新通过 Tampermonkey 检查即可；**仅上传到 GitHub 不会令以前安装的脚本自动具备更新地址**。

**发布新版：**

1. 编辑仓库根目录的 `ucas-study.user.js`，保持文件名和路径不变。
2. 同时增加头部的 `// @version` 和源码中的 `const VERSION`，例如从 `1.4.0` 升为 `1.4.1`。
3. 提交到 `main` 分支，等 GitHub Raw 文件可访问后，Tampermonkey 才能发现更新。
4. 在 Tampermonkey 中检查脚本自动更新是否启用；也可以在管理面板手动检查更新。更新时间取决于扩展设置、网络及浏览器运行状态，**不是推送到 GitHub 就立刻同步**。

本项目目前假定仓库使用 `main` 分支。如果你改用其他默认分支，必须同步修改脚本中的两个 URL，已经安装的旧客户端也需要重新导入正确版本。

## ⚙️ 配置选项

| 设置项 | v1.4 默认值 | 作用 |
| --- | --- | --- |
| DeepSeek API Key | 空 | 首次使用必须填写，形如 `sk-...` |
| 模型 | `deepseek-flash` | 可以在面板中更换为自己的 API 当前支持的模型名称 |
| 播放速度 | `1.5×` | 可选择 `1×`、`1.25×`、`1.5×`、`1.75×`、`2×` |
| 自动切换下一课程 | 开启 | 当前视频正常结束后继续下一个未完成课程 |
| 刷新后定位未完成视频 | **开启** | 启动时先读取目录标记，不能直接播放网页默认课程 |
| 视频完成后刷新网页 | **开启** | 正常结束后等待平台写入记录，然后刷新网页重新获取进度 |
| 检测到题目自动调用 DeepSeek | 开启 | 自动解题，无需手动触发 |
| 自动勾选答案 | 开启 | 自动选择 AI 建议的选项，并检查选中状态 |
| 自动提交视频习题 | 开启 | 仅在实际选项与建议答案完全一致时尝试提交 |
| 刷新后自动恢复 | 开启 | 已配置 API Key 时自动恢复运行 |

**模型注意：** 上表中的 `deepseek-flash` 是脚本当前的默认配置，并不表示该模型在所有时间、所有账户下均可调用。如果接口返回模型不存在或不支持某项参数，请根据 [DeepSeek API 文档](https://api-docs.deepseek.com/) 调整模型名称和接口兼容性。

## 🆕 v1.4 更新：刷新后自动查找未完成课程

网站在课程内部切换视频时，并不会同步修改浏览器地址栏的课程 `id`。因此即使上一节已经学完，刷新后平台仍可能按旧 URL 选中 JCXL01 等已完成课程。此前脚本在初始化后直接尝试播放默认视频，于是出现重复观看的现象。

v1.4 修改为：

1. **进入网页或刷新后不立即播放**，先等待课程树的数据加载。
2. 按网页目录顺序扫描各大章节，识别 `(学完)`、`(未学)`、`(44%)` 等标记。`(学完)` 或 `(100%)` 跳过，未学或不足 100% 的视频属于待完成课程。
3. 如有必要，展开尚未展开的大章节；遇到第一个待完成视频，就通过站点原本的课程树点击进入。
4. **确认当前视频或标题确实完成切换，才允许自动播放**；如果目录未加载或切换失败，停下来并在日志中提示，避免误播已完成课程。
5. 视频自然结束后，留出约 8.5 秒让网站记录完成进度，然后执行正常刷新；刷新完成后重新执行 1–4。

这两项行为均可在设置中独立关闭：**「进入或刷新网页时，自动定位首个未完成视频」**、**「视频正常结束后刷新网页，读取平台最新进度」**。建议保持开启。

**注意：** 这只使用网页显示的服务器返回进度，不主动改写数据库，也无法保证平台记录成功。如果服务器尚未把本节标记为完成，刷新后它仍会被判定为未完成，脚本可能再次播放该节。请检查右侧日志和左侧真实进度标记。

## 🛠️ v1.3 更新：修复多选题只选中一项

部分多选题使用 Vue / Ant Design Vue 的 `checkbox-group`。如果脚本连续同步点击 A、C，后一次的状态更新可能覆盖前一次，导致只勾选 C。

v1.3 改为：

1. 按 DeepSeek 返回的答案逐项点击。
2. 每次点击后等待网页状态更新，并确认该选项已选中。
3. 全部处理完成后，再检查**所有选项**的真实选中状态。
4. 只有实际选项与 AI 返回的答案完全一致，才允许自动提交；不一致时停止提交并保留弹窗供人工处理。

脚本不会自动覆盖已经由用户手动勾选的选项。

## ❓ 常见问题

<details>
<summary>弹出题目后没有自动答题？</summary>

确认脚本正在运行、已填写 API Key，且已开启「检测到习题时自动调用 DeepSeek」。目前仅针对课程视频中的「视频习题」弹窗，**不处理考试页面**。如果网站改版，题目结构可能需要重新适配。
</details>

<details>
<summary>显示 DeepSeek HTTP 错误？</summary>

检查 API Key、账户余额、网络连接，以及「模型」是否被当前 DeepSeek API 支持。可以展开日志查看具体报错。图片选项还要求所选模型和接口支持图片输入。
</details>

<details>
<summary>多选题为什么没有提交？</summary>

v1.3 会核对最终勾选结果。如果 DeepSeek 只返回一个选项，或者 Vue 页面中的复选框状态与建议答案不一致，就可能保留题目供人工处理。先查看日志中的「DeepSeek 建议」和「已核验勾选完成」信息。
</details>

<details>
<summary>视频播放完了，没有自动进入下一课？</summary>

确认已启用「自动切换下一课程」「刷新后定位未完成视频」「视频完成后刷新网页」。刷新后先等待课程树加载。若页面显示的完成进度没有更新，脚本会把原视频视为未完成；请检查后台是否成功记录，并查看助手日志。
</details>

<details>
<summary>网页上的操作面板不出现？</summary>

确认网址属于 `ucas.jcedutec.cn`，脚本已启用，并刷新课程页。若同时安装其他实验室安全助手，请先停用，避免冲突。
</details>

<details>
<summary>打开脚本时中文显示乱码？</summary>

请使用 UTF-8 编码打开文件。仓库中的 `ucas-study.user.js` 使用 UTF-8 BOM 以改善部分 Windows 编辑器的识别情况。
</details>

## 🔐 隐私、安全与限制

- **不要将 API Key 上传到 GitHub。** 请在油猴脚本的设置面板中填写，脚本通过 Tampermonkey 存储设置。
- 请求直接发送至 `https://api.deepseek.com/chat/completions`；题目文字、选项文本及可能存在的图片 URL 会被发送给 DeepSeek 进行分析。请确认符合自己的数据使用要求。
- AI 可能产生错误答案或无法判断的结果；**尤其是实验室安全题目，请以学校要求和正式安全规范为准**。
- 仅适配已确认的网站视频习题 DOM；题型、页面结构或接口升级后可能失效。
- 不绕过平台对视频播放的限制，不伪造学习时长或完成状态，也不自动提交整场考试。
- 如遇系统异常，请先点击「暂停」，必要时禁用脚本并使用原网页完成学习。
